# 🚀 Featured Project

## 🛒 Mercadito

**Mercadito** is a shopping management application designed to make household shopping easier, more organized, and more practical.

The idea started with a simple question:

> 🛍️ **Why should managing your shopping list be complicated?**

### ✨ Features

* 📝 Shopping lists
* 💰 Budget management
* 🛍️ Product tracking
* 📊 Purchase tracking
* 📱 Mobile-first experience
* ☁️ Cloud synchronization
* 🔐 Authentication

### 🧰 Technology

```text
React
JavaScript
Supabase
```
